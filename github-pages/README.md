# Field Notes on the Spirits of the Island

An unofficial fan field guide to all 37 Spirit Island spirits, arranged by habitat, each with an original watercolor plate and a three-turn opening.

Spirit Island is a game by R. Eric Reuss, published by Greater Than Games. This guide isn't affiliated with them. The plates are original watercolor studies of each spirit's terrain, not game art. Openings are compiled from the community sources listed on each page.
